# claude-odometer

[![test](https://github.com/nxhung1610/claude-odometer/actions/workflows/test.yml/badge.svg)](https://github.com/nxhung1610/claude-odometer/actions/workflows/test.yml)

A Claude Code mod that shows your account's 5-hour and 7-day usage limits on a line right above the prompt, each with a bar and its reset time, and below it how fast the model is answering.

![The quota row at three levels: 23% in green, 75% in amber, 91% in red](docs/quota.svg)

## What it shows

**Quota.** Green under 70%, amber from 70%, red from 90%. `↻` marks the reset time: just the time if it is later today, otherwise the weekday and time.

**Speed.** The row beneath the quota shows the latest model step's TTFT (time to first output) and TPS (output tokens per second). While a step runs, it also shows how long the step has run, and a light moves across the word `working`.

![While a step runs, a light moves across the word working, one letter at a time](docs/speed.svg)

**`/tokens`.** A pane with tokens per day by model, for the last 7 days, the last 30 days, or all time. It reads your transcripts; the numbers in the image are example data.

![The /tokens pane: a stacked column chart of tokens per day, with a legend for Opus, Sonnet and Haiku](docs/tokens.svg)

## Install

In a terminal Claude Code session, version 2.1.275 or later, type:

```text
/plugin install odometer --marketplace nxhung1610/claude-odometer
```

Answer `y` to add the marketplace, then press Enter to take the default user scope. The mod is active in that session, and in each session you start after.

To run it from a clone, as you would while developing it:

```bash
git clone https://github.com/nxhung1610/claude-odometer.git
claude --plugin-dir /path/to/claude-odometer
```

`/tokens` runs `hooks/scan_usage.py` with Python 3, found as `python3` or `python` on your `PATH`.

## Development

```bash
claude plugin test        # run the test suite
claude plugin validate .  # check the manifest and hooks
python3 -m unittest discover -s hooks -p 'test_*.py'  # the transcript scanner's tests
```

`.claude-plugin/types/` is generated by Claude Code when it loads the mod, so it is not committed.

The plugin is named `odometer` in `plugin.json`. The repository is `claude-odometer`, but a third-party plugin name cannot start with `claude-`. The state the mod keeps is stored under the plugin's name.

CI (`.github/workflows/test.yml`) runs the validation, the plugin tests and the scanner tests on Ubuntu and Windows, on pull requests and on pushes to `main`, with Claude Code 2.1.299.

## How it works

- `session.start` reads the current rate-limit windows.
- `session.measure` updates them when the engine reports a change in a window.
- `ui.render` on `AbovePrompt` draws the quota on one row of the band above the prompt, and the model's speed on the row beneath. The band yields while a survey holds it.
- `turn.step` times each model step. TTFT is the wait from the step's start to its first output: a chunk of text, thinking, a tool call, or its input. TPS is the step's output tokens per second from that output to its stop. While a step runs, the band redraws ten times a second: it shows how long the step has run, and a light moves across the word `working`.
- `/tokens` opens a pane with tokens per day by model, for the last 7 days, the last 30 days, or all time. It runs `hooks/scan_usage.py` with Python 3 over the transcripts in `~/.claude/projects`. The script parses each transcript line, but keeps only each response's usage counts, model and timestamp, plus a count of sessions; it sends nothing anywhere.

## Files

- `.claude-plugin/`: `plugin.json`, and `marketplace.json`, which the install line above reads
- `bin/install.js`, `package.json`: an installer that runs the install line above through the Claude Code CLI, and its npm metadata
- `docs/*.svg`: the illustrations above; the numbers in the tokens chart are example data
- `hooks/register.tsx`: hooks, the quota and speed rows above the prompt, and the `/tokens` pane
- `hooks/timing.ts`: the speed row's text, the TTFT and TPS arithmetic, and the light's position
- `hooks/format.ts`: bar, tone, and reset-label helpers
- `hooks/tokens.ts`: the `/tokens` chart and summary helpers
- `hooks/scan_usage.py`: counts tokens per day and model from the transcripts
- `hooks/*.test.ts`, `hooks/test_scan_usage.py`: tests
- `types/index.d.ts`: the `QuotaWindow` and `ModelSpeed` types, and the plugin state declaration

Tested with Claude Code 2.1.299.
